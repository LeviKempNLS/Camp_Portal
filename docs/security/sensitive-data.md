# Sensitive data

Medical, insurance, medication, dietary, and health-history data is restricted to need-to-know users. It must be encrypted in transit, excluded from application logs, protected by server-side permission checks, and audited when read or changed. Final retention rules require camp leadership approval before deletion is implemented.

The browser-only draft demonstration is not a production medical-data store. Before collecting real registrations, replace it with authenticated server persistence and perform a security review.
